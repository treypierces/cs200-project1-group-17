## Actors
1. Provider - Interacts with the terminal and enters information such as number, service date, service code, and swipes member cards.
2. Manager - Can request a report to run and the account payable summary goes to them.
3. Operator - Runs the software using the interactive mode and adds, deletes, and updates member and provider records.
4. Acme Accounting Services - Handles fee payments, overdue members, and updates ChocAn membership records nightly.
5. Member - Receives a weekly report, which is output from the system.
6. EFT System - Writes an EFT file containing a report of the funds transfer (who and how much) for use by a consumer.
